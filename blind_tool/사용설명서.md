# 기록물 비식별(블라인드) 처리 도구

스캔한 입양기록물 등에서 개인정보를 사람이 직접 검은 박스로 가리고, 결과를 PDF로 출력하는 **오프라인 프로그램**입니다.
삭제한 페이지와 가린 항목은 **비식별 안내표**(엑셀·PDF)에 자동으로 정리됩니다.

- 인터넷 연결을 사용하지 않습니다. 기록물 이미지는 PC 밖으로 나가지 않습니다.
- 그래픽카드가 필요 없습니다.
- 원본 파일은 수정하지 않습니다.

## 1. 설치

**방법 A. 실행 파일 받기 (권장)**
GitHub 저장소의 Actions → "비식별 도구 Windows 빌드" → 최근 실행 → `BlindTool-windows` 를 내려받아 압축을 풉니다.
폴더째 작업 PC에 복사한 뒤 `BlindTool.exe` 를 실행합니다.

**방법 B. 직접 만들기**
인터넷이 되는 Windows PC에 Python 3.10 이상을 설치하고 `build_windows.bat` 을 실행합니다.
`dist\BlindTool` 폴더가 만들어지면 USB 등으로 작업 PC에 복사합니다.

**방법 C. Python으로 바로 실행**
`pip install -r requirements.txt` 후 `python app.py`

## 2. 작업 순서

1. 기록물 스캔 파일(JPG·PNG·TIF·BMP·PDF)을 한 폴더에 넣습니다. 하위 폴더도 읽습니다.
   파일 이름 순서(숫자는 크기 순)로 페이지가 나열됩니다.
2. **[폴더 열기]** 로 그 폴더를 선택하고, **작업자** 이름을 입력합니다.
3. 페이지마다:
   - 숫자키 **1~9** 로 가릴 항목을 고르고, 가릴 부분을 마우스로 **드래그**합니다.
   - 결과물에서 뺄 페이지는 **삭제 사유**를 고르고 **[이 페이지 삭제]** 를 누릅니다.
   - 필요하면 **비고**를 적습니다(안내표에 들어감).
   - 확인이 끝나면 **Enter** (페이지 확정 후 다음).
4. 모든 페이지를 확정하면 **[내보내기]** 를 누릅니다.

작업 내용은 박스 하나를 그릴 때마다 폴더 안 `_비식별작업.json` 에 자동 저장됩니다.
프로그램을 껐다 켜도 같은 폴더를 열면 이어서 작업할 수 있습니다.

## 3. 블라인드 박스가 바뀌지 않도록 한 장치

| 단계 | 장치 |
|---|---|
| 편집 중 | 박스는 **옮기거나 크기를 바꾸는 기능이 없습니다**. 잘못 그린 박스는 확인 창을 거쳐 삭제만 할 수 있습니다. |
| 확정 후 | 확정한 페이지는 박스 추가·삭제, 페이지 삭제, 비고 수정이 모두 막힙니다. 확정을 해제하려면 이유를 적어야 하고 처리 이력에 남습니다. |
| 내보내기 | 모든 페이지를 확정해야 내보낼 수 있습니다(설정으로 변경 가능). |
| 결과 PDF | 검은 박스를 **이미지 픽셀에 직접 칠한 뒤** 이미지만으로 PDF를 만듭니다. 글자 층·주석·레이어가 없어서 박스를 들어내거나 복사해도 원문이 나오지 않습니다. |
| 결과 PDF | 편집·주석 권한을 잠근 상태로 저장합니다(인쇄만 허용). |
| 검증 | 내보낸 직후 PDF를 다시 열어 모든 박스 위치가 검게 덮였는지, 글자 층·주석이 없는지 자동 검사합니다. 실패하면 경고합니다. |
| 변조 확인 | 결과 PDF의 SHA-256 값을 안내표와 `SHA256.txt` 에 남깁니다. 나중에 같은 값이 나오면 파일이 바뀌지 않은 것입니다. |

> 참고: PDF 권한 잠금은 일부 프로그램에서 무시될 수 있습니다. 그러나 가린 부분의 원래 글자는 결과 PDF 안에 **아예 존재하지 않으므로** 어떤 방법으로도 되살릴 수 없습니다.

## 4. 결과물

원본 폴더(또는 선택한 폴더) 안에 `_비식별결과_날짜_시간` 폴더가 만들어집니다.

- `폴더명_비식별.pdf` — 가림 처리된 결과물(삭제 페이지 제외)
- `폴더명_비식별안내표.xlsx` — 안내표 시트 + 처리 이력 시트
- `폴더명_비식별안내표.pdf` — 안내표 인쇄용
- `SHA256.txt` — 결과 PDF 지문값

안내표 열: 연번 / 원본 파일 / 원본 쪽 / 출력 쪽 / 처리 구분(공개·부분공개·비공개(삭제)) / 비식별 항목(개수) / 가린 영역 수 / 삭제 사유 / 비고 / 확정자 / 확정 일시

## 5. 기관 기준에 맞게 바꾸기 (`config.json`)

메모장으로 `config.json` 을 열어 고칩니다.

- `categories` — 가릴 항목 목록(최대 9개가 숫자키에 연결)
- `delete_reasons` — 페이지 삭제 사유 목록
- `status_labels` — 처리 구분 명칭
- `pdf_dpi` — PDF 원본을 읽을 해상도(기본 300)
- `box_padding_px` — 박스 바깥으로 더 칠할 여유(픽셀)
- `require_all_confirmed` — 모든 페이지 확정 전 내보내기 금지(true 권장)
- `lock_pdf_permissions` — 결과 PDF 편집 권한 잠금
- `attach_table_to_pdf` — 안내표를 결과 PDF에 붙일지 기본값(`none`/`front`/`back`)

## 6. 단축키

| 키 | 동작 |
|---|---|
| 1~9 | 가릴 항목 선택 |
| 마우스 드래그 | 박스 추가 |
| 박스 클릭 | 박스 선택 |
| Del | 선택 박스 삭제(확인 창) |
| Ctrl+Z | 마지막 박스 취소(확인 창) |
| Enter | 페이지 확정 후 다음 미확정 페이지로 |
| PgDn / PgUp | 다음 / 이전 페이지 |
| Ctrl+휠, Ctrl +/− | 확대 / 축소, Ctrl+0 화면 맞춤 |
