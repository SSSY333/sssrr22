# 기록물 비식별(블라인드) 처리 도구

스캔한 입양기록물에서 개인정보를 **비식별 기준표**에 따라 검은 박스로 가리고 PDF로 출력하는 **오프라인 프로그램**입니다.
처리한 쪽수는 기준표의 "비식별 처리 면(Redaction Page)" 칸에 자동으로 채워집니다.

- 인터넷 연결을 사용하지 않습니다. 기록물 이미지는 PC 밖으로 나가지 않습니다.
- 그래픽카드가 필요 없습니다.
- 원본 파일은 수정하지 않습니다.

## 1. 설치

**방법 A. 실행 파일 받기 (권장)**
GitHub 저장소의 Actions → "비식별 도구 Windows 빌드" → 최근 실행 → `BlindTool-windows` 를 내려받아 압축을 풉니다.
폴더째 작업 PC에 복사한 뒤 `BlindTool.exe` 를 실행합니다. 문자 인식 엔진(Tesseract, 영어·한국어·한자)이 함께 들어 있습니다.

**방법 B. 직접 만들기**
인터넷이 되는 Windows PC에 Python 3.10 이상과 Tesseract OCR(UB Mannheim 배포판, 설치 시 Korean 선택)을 설치하고 `build_windows.bat` 을 실행합니다.
`dist\BlindTool` 폴더를 USB 등으로 작업 PC에 복사합니다.

**방법 C. Python으로 바로 실행**
`pip install -r requirements.txt` 후 `python app.py`

## 2. 작업 순서

1. 기록물 스캔 파일(JPG·PNG·TIF·BMP·PDF)을 한 폴더에 넣습니다. 파일 이름 순서(숫자는 크기 순)로 페이지가 나열됩니다.
   파일 이름에는 개인정보(이름 등)를 넣지 마세요. 내부 처리내역에 그대로 기록됩니다.
2. **[폴더 열기]** 로 폴더를 선택하고 **작업자** 이름을 입력합니다.
3. 페이지마다:
   - 오른쪽 **비식별 기준 가이드**에서 선택한 항목의 기준(무엇을 공개하고 무엇을 가리는지)을 확인합니다.
   - 타이핑된 친생부모 정보가 있으면 **자동 인식 제안**(파란 점선)이 뜹니다. 위치를 확인하고 **[선택 적용]**/**[모두 적용]**, 틀린 제안은 **[무시]** 합니다.
   - 손글씨나 제안에 없는 정보는 숫자키 **1~9** 로 항목을 고르고 마우스로 **드래그**해서 직접 가립니다.
   - 면 전체를 빼야 하는 문서(친생부모 호적·주민등록 서류, 양부모 서류, 위탁가정 사진 등)는 **삭제 사유**를 고르고 **[이 페이지 삭제]** 를 누릅니다.
   - 확인이 끝나면 **Enter** (페이지 확정 후 다음). 적용하지 않은 제안이 남아 있으면 한 번 더 묻습니다.
4. 모든 페이지를 확정하면 **[내보내기]** 를 누릅니다.

작업 내용은 박스 하나를 그릴 때마다 폴더 안 `_비식별작업.json` 에 자동 저장됩니다. 같은 폴더를 다시 열면 이어서 작업할 수 있습니다.

## 3. 비식별 기준 (config.json 의 rules)

| 기준 | 구분 | 대상 | 방식 | 프로그램에서 |
|---|---|---|---|---|
| R1 | 친생부모 서류 | 호적등본부, 주민등록표 등본, 주민등록증, 인감증명서 | 일체 삭제 | 페이지 삭제 사유 |
| R2 | 친생부모 서류 | 친권포기서류, 입양동의서 / 친생부모 이름(성 제외), 출생 월일, 세부 주소*, 친생부모 외 친가족 정보** | 부분 삭제 | 항목 1~4 |
| R3 | 양부모 서류 | 양부모 조사서, 입양 행정 서류, 입양 전 양부모 사진 | 일체 삭제 | 페이지 삭제 사유 |
| R4 | 위탁 가정 | 사진 | 일체 삭제 | 페이지 삭제 사유 |
| R5 | 위탁 가정 | 개인정보(이름, 주민등록번호, 주소 등) | 부분 삭제 | 항목 5 |
| R6 | 입양 종사자 | 민감정보(주민등록번호, 본적) | 부분 삭제 | 항목 6 |
| R7 | 기관내·기관간 서류 | 입양인이 수/발신인이 아닌 문서 | 일체 삭제 | 페이지 삭제 사유 |
| R8 | 타 입양인·제3자 | 개인정보 | 일체 삭제 | 페이지 삭제 사유 |
| R9 | 타 입양인·제3자 | 개인정보 | 부분 삭제 | 항목 7 |
| R10 | 미아 발견자*** | 이름을 제외한 개인정보 | 부분 삭제 | 항목 8 |

\* 입양인 주소와 친생부모 주소가 같으면 공개(같다는 사실은 공개 불가) · \*\* 아동과의 관계는 공개 · \*\*\* 발견 장소가 발견자 주소와 같으면 공개(같다는 사실은 공개 불가)

항목 9 "기타"와 삭제 사유 "기타"는 기준표에 없는 처리입니다. 비고에 사유를 꼭 적으세요(내부 처리내역에만 남음).

## 4. 자동 인식 제안 (타이핑된 친생부모 정보)

- 페이지를 열면 뒤에서 문자 인식을 하고, 친생부모 칸의 정보를 찾아 **제안**합니다. 나머지 페이지도 차례로 미리 분석합니다.
  - 이름: 성은 남기고 이름만 (`Koh, Mee Young` → `Mee Young`, `김영희` → `영희`)
  - 출생일: 연도는 남기고 월·일만 (`1955. 3. 2` → `3. 2`, `Oct. 12, 1958` → `Oct. 12,`)
  - 주소: 시·군·구는 남기고 세부 주소만 (`서울특별시 종로구 혜화동 12번지` → `혜화동 12번지`)
  - 한 번 찾은 친생부모 이름이 본문 등 다른 곳에 다시 나오면 그것도 제안합니다.
- 아동(Child) 칸의 정보는 제안하지 않습니다.
- **제안은 자동으로 가려지지 않습니다.** 사람이 확인하고 적용해야 블라인드 박스가 됩니다.
- 손글씨, 흐린 스캔, 특이한 서식은 인식되지 않거나 틀릴 수 있습니다. 제안이 없다고 가릴 정보가 없는 것은 아닙니다.
- 문자 인식 결과는 메모리에만 두고 파일로 저장하지 않습니다.

## 5. 블라인드 박스가 바뀌지 않도록 한 장치

| 단계 | 장치 |
|---|---|
| 편집 중 | 박스는 **옮기거나 크기를 바꾸는 기능이 없습니다**. 잘못 그린 박스는 확인 창을 거쳐 삭제만 할 수 있습니다. |
| 확정 후 | 확정한 페이지는 박스 추가·삭제, 페이지 삭제, 비고 수정이 모두 막힙니다. 확정 해제는 이유를 적어야 하고 처리 이력에 남습니다. |
| 내보내기 | 모든 페이지를 확정해야 내보낼 수 있습니다(설정으로 변경 가능). |
| 결과 PDF | 검은 박스를 **이미지 픽셀에 직접 칠한 뒤** 이미지만으로 PDF를 만듭니다. 글자 층·주석·레이어가 없어 박스를 들어내도 원문이 나오지 않습니다. 편집 권한도 잠급니다(인쇄만 허용). |
| 검증 | 내보낸 직후 PDF를 다시 열어 모든 박스 위치가 검게 덮였는지, 글자 층·주석이 없는지 자동 검사합니다. |
| 변조 확인 | 결과 PDF의 SHA-256 값을 내부 처리내역과 `SHA256.txt` 에 남깁니다. |

> PDF 권한 잠금은 일부 프로그램에서 무시될 수 있지만, 가린 부분의 원래 글자는 결과 PDF 안에 **아예 존재하지 않으므로** 되살릴 수 없습니다.
> 단, 박스가 글자를 다 덮었는지는 사람이 확인해야 합니다.

## 6. 결과물

원본 폴더(또는 선택한 폴더) 안에 `_비식별결과_날짜_시간` 폴더가 만들어집니다.

| 파일 | 용도 |
|---|---|
| `폴더명_비식별.pdf` | 가림 처리된 결과물(삭제 페이지 제외). 선택 시 안내표를 앞/뒤에 첨부 |
| `폴더명_비식별안내표.pdf` | **입양인 안내용**: 공개 범위 안내문 + 비식별 기준표(처리 면 기재) |
| `폴더명_내부용_처리내역.xlsx` | 기준표 시트 / 페이지별 처리내역 시트 / 처리 이력 시트 |
| `폴더명_내부용_처리내역.pdf` | 페이지별 처리내역 인쇄용 |
| `SHA256.txt` | 결과 PDF 지문값 |

"비식별 처리 면" 표기:
- 부분 삭제: 결과 PDF의 쪽 번호 (예: `p. 2, 5-7`). 안내표를 결과 PDF 앞에 붙이면 그만큼 밀린 번호로 적습니다.
- 일체 삭제: 결과물에 없으므로 면 수와 원본 기록물 기준 쪽 번호 (예: `2면 삭제 (원본 p. 4, 9)`)

## 7. 설정 바꾸기 (`config.json`)

메모장으로 `config.json` 을 열어 고칩니다.

- `rules` — 비식별 기준표 각 행(구분, 대상, 방식). 안내표에 이 순서로 나옵니다.
- `box_categories` — 가릴 항목(최대 9개, 숫자키). `rule` 로 기준표 행에 연결, `guide` 는 화면 가이드 문구
- `delete_reasons` — 페이지 삭제 사유. `rule` 로 기준표 행에 연결
- `notice_title`, `notice_text`, `include_notice` — 안내문 내용과 포함 여부
- `footnotes` — 기준표 아래 주석
- `auto_guide` — 자동 인식 제안 사용 여부
- `pdf_dpi`, `box_padding_px`, `jpeg_quality`, `require_all_confirmed`, `lock_pdf_permissions`, `attach_table_to_pdf`
