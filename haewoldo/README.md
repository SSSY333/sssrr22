# 해월도 마을생활 (v0.3)

쿼터뷰 섬마을 생활 시뮬레이션 + 연애 게임. 다섯 직업 중 하나로 해월도에서 지내면서
**파출소 형사님**과 만나고, 함께 걷고, 앉고, 낚시하고, 데이트하며 관계를 키워 갑니다.
모바일 세로 화면에 맞췄고, 캐릭터·건물·지형은 모두 코드로 한 픽셀씩 그린 픽셀아트입니다 (외부 이미지 없음).


## v0.3 업데이트
- **섬이 약 7.7배 넓어짐** (46×46 → 128×128). 가운데 해월 마을을 중심으로 동쪽 포구(횟집·해녀창고·무인도 배), 해수욕장, 귤 농장 마을, 조랑말 목장, 해월 오름 전망대, 동백숲·정자·연못, 풍차 언덕, 등대, 서쪽 갯바위, 꽃밭 들판
- **🚌 마을버스** 정류장 9곳 — 먼 곳은 버스로 15분 (형사님과 동행 중이면 같이 타요)
- **지도**: 평소엔 접힌 버튼, 누르면 섬 전체 지도가 크게 펼쳐지고 확대해서 볼 수 있어요. 누른 곳으로 걸어가요
- 화면에 보이는 바닥만 매 프레임 그려서 큰 섬에서도 메모리를 적게 쓰고 60fps 유지, 길찾기는 이진 힙 A*로 빠르게
- **실내 가구 재배치**: 가구를 뒤쪽 벽을 따라 가지런히, 가운데는 비워 두고, 방 전체가 한 화면에 보이게
- **나무 줄이기**: 마을 안 나무를 크게 줄이고 숲 지역에 모음
- **주민 속도를 저마다 다르게** (할머니는 느릿느릿, 아이는 총총), 형사님도 조금 천천히
- **주민이 건물 안팎을 오가요**: 시간에 따라 학교 · 카페 · 횟집 · 회관 · 보건지소 · 슈퍼 · 해녀창고에 들어갔다 나와요
- 새 주민 4명(목장 아저씨, 농장 아주머니, 등대지기 할아버지, 해변 안전요원), 조랑말 2마리, 새 데이트 장소 4곳

> v0.2 저장 데이터와는 지도가 달라 호환되지 않아 새로 시작해요.

## v0.2 업데이트
- **시작 화면**: 움직이지 않는 섬마을 그림 + 「해월도 마을생활 / 해월도에 어서오세요」
- **부드러운 화면**: 카메라는 소수 단위로 따라가고 그림은 장치 픽셀마다 맞춰 그려서 걸을 때 자글거림·끊김 없음
- **넓어진 섬(46×46)** + 접었다 펴는 **미니맵**(누르면 그곳으로 걸어감)
- 새 장소: 갯바위 낚시터, 경찰 사택, 해월 횟집, 마을회관, 해녀창고(불턱 대신), 숲길·정자·연못, 해수욕장, **배 타고 가는 무인도**
- **건물 내부 10곳**(집·파출소·카페·횟집·마을회관·슈퍼·학교·보건지소·해녀창고·사택)과 내부 행동, **내 집 꾸미기**(가구 20여 종 구입·배치·회전·보관)
- **주민 12명 + 고양이 3마리 · 강아지 2마리**(누르면 반응, 잠깐 따라오다 제 갈 길로)
- 고르지 않은 직업은 **여성 주민**으로 등장해 형사님과 산책하며 질투를 유발 (연애 대상 아님, 연인이 되면 사라짐)
- **7월 1일 여름 시작**, 한 달 10일 · 계절 30일(현실 약 8~9시간). 계절별 풍경(잔디·나무·눈 덮인 지붕·꽃)·옷차림·대사, **계절 행사 19종**
- **배경음악**(Web Audio로 직접 연주, 낮·노을·밤·계절마다 다름) + 아주 작은 파도 소리
- 섬 활동: 장소·계절별 낚시와 물고기 도감, 썰물 조개 줍기, 겨울 귤 따기, 별 보기, 노래방, 물회, 분실물 찾기
- 관계 **8단계**(… 연인 → 깊어진 연인 → 약혼 → 부부), 하루 호감도 한도와 반복 감소로 난이도 상승
- 스킨십·데이트 확장(볼 뽀뽀·뽀뽀·업어주기·무릎베개·백허그…, 데이트 16곳), 애칭 정하기, 기념일, 다툼과 화해, 간호
- **만난 지 1년 후 프로포즈**, 결혼식 날짜는 직접 선택, 해수욕장 결혼식, 함께 사는 신혼 생활
- **형사님 이름**: 새 게임에서 정하거나 메뉴에서 변경. 호칭은 형사님 → OO 씨·이름 → 애칭 → 여보

## 실행
빌드가 필요 없는 정적 페이지입니다.

```bash
cd haewoldo
python3 -m http.server 8000
# http://localhost:8000 (같은 Wi-Fi 휴대폰에서는 http://<PC IP>:8000)
```

## Alpha 0.1 구현 범위
1. **파출소 형사님 NPC** — 키 크고 어깨 넓은 SD 캐릭터, 근무복(남색 제복·배지) / 퇴근 후 평상복(소매 걷은 셔츠)
2. **자율 일과** — 07시 출근 → 오전 마을 순찰 → 12시 카페 벤치 점심 → 파출소 → 15시 부두 순찰 → 17시 퇴근 산책 → 19시반 부두 낚시 → 22시 귀가
3. **직업별 첫 만남** — 의사(다친 할머니를 업고 옴), 선생님(등굣길 순찰), 여행객(날아간 지도), 카페 사장님(개업 첫 손님), 해녀(너울 경고)
4. **대화와 선택지** — 단계별 대화 주제, 선택에 따라 다른 대답·표정(초상화 8종)·호감도
5. **호감도와 6단계 관계** — 대화 버튼을 반복해서는 오르지 않음 (하루 대화 2회까지만 호감도). 함께 보낸 시간, 활동, 선택, 이벤트 완료가 조건
6. **함께 다니기** — 형사님이 플레이어가 걸어온 길을 따라오고, 멈추면 옆자리에 섬. 가만히 있으면 두리번거리거나 말을 검. 근무 중에는 90분 제한, 밤에는 거절
7. **함께 앉기** — 카페 테라스 · 부두 · 등대 · 언덕 전망대 벤치, 장소 × 관계 단계별 대사
8. **이벤트** — 첫 만남, 첫 산책, 나란히 앉은 시간, 부두에서 기다려 준 사람, 야간 순찰 중 우연히, 우산 하나 두 사람(비 오는 날), 고백(수락 · 보류 · 거절 모두 가능, 플레이어가 먼저 고백도 가능)
9. **연인 콘텐츠(5단계)** — 데이트 8곳, 손잡기 · 팔짱 · 안아주기 · 머리 쓰다듬기, 사진 찍기
10. **추억 앨범** — 이벤트 순간을 픽셀 스냅샷으로 날짜 · 장소와 함께 저장
11. **마을생활** — 직업 일하기(돈 · 직업 레벨), 마을 슈퍼(선물 구입 · 해산물 판매), 낚시 미니게임, 주민 3명, 날씨(맑음 · 흐림 · 비), 낮/노을/밤 조명과 등대 불빛
12. **자동 저장** — 15초마다, 이벤트 직후, 앱을 내릴 때 `localStorage`에 저장. 이어하기 시 위치 · 시간 · 관계 · 이벤트 진행 · 동행 상태 · 앨범 복원

## 파일
- `index.html` — 화면 구조 (HUD, 대화창, 메뉴 시트, 관계 화면, 타이틀)
- `style.css` — 모바일 세로 UI
- `js/sprites.js` — 픽셀아트 생성기 (SD 캐릭터, 초상화 표정, 타일, 소품, 건물)
- `js/world.js` — 섬 지도, 건물 · 벤치 · 장소, A* 길찾기
- `js/content.js` — 직업, 관계 단계, 아이템, 대사 · 이벤트 텍스트
- `js/audio.js` — 배경음악 · 파도 · 효과음
- `js/engine.js` — 상태 · 캐릭터 · 렌더링 · 지도 이동 · 입력 · 미니맵
- `js/story.js`, `js/story2.js` — 대화 · AI · 관계 · 이벤트 · 활동 · 화면 · 메인 루프

브라우저 콘솔의 `HW` 객체로 상태를 볼 수 있습니다 (예: `HW.S.rel`).
