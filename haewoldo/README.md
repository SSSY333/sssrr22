# 해월도 다이어리 (v0.9.10)

> 예전 이름: 해월도 마을생활 (v0.9.5까지). 앱 내부 ID(`com.haewoldo.village`)와 저장 데이터는 그대로라 덮어 설치하면 이어서 할 수 있어요.

쿼터뷰 섬마을 생활 시뮬레이션 + 연애 게임. 다섯 직업 중 하나로 해월도에서 지내면서
**파출소 형사님**과 만나고, 함께 걷고, 앉고, 낚시하고, 데이트하며 관계를 키워 갑니다.
모바일 세로 화면에 맞췄고, 캐릭터·건물·지형은 모두 코드로 한 픽셀씩 그린 픽셀아트입니다 (외부 이미지 없음).

## v0.9.10 실내 화면 크기 · 자잘한 수정

- 「을(를) · 이(가) · (으)로」처럼 나오던 조사 34곳을 이름에 맞게 자동으로
- 무작위 장기 플레이 점검(직업 3종 × 약 850행동 · 1,100여 문장): 오류 · 막힌 길 · 깨진 문장 없음

- 집 조리대 「요리」: 작물마다 다른 요리 10가지 — 상추 겉절이 · 감자전 · 버터 옥수수 · 토마토 달걀볶음 · 수박화채 · 딸기 찹쌀떡 · 당근 케이크 · 단호박 푸딩 · 배추 된장국 · 시금치 주먹밥
- 재료 두 가지 특별 요리 3가지 — 고기 상추쌈(상추+바비큐 고기) · 감자 당근 카레 · 토마토 상추 샌드위치
- 요리마다 다른 손질 · 조리 과정, 요리 요령 고르기(맞히면 2인분), 요리마다 다른 형사님 반응 · 먹을 때 묘사
- 형사님과 같이 요리 → 같이 먹기(호감도 · 앨범), 레시피 수첩(처음 만든 요리 기록, 전부 모으면 요리왕), 소지품에서 눌러 먹기 · 선물 · 판매

## v0.9.2 텃밭 · 컬러 이모지
- **텃밭**: 집 뒤 6칸 밭. 슈퍼 「씨앗 · 모종」에서 계절 씨앗(상추 · 감자 · 옥수수 · 토마토 · 수박 · 딸기 · 당근 · 호박 · 배추 · 시금치) 구입 → 심기 → 매일 물 주기(비 오면 자동) → 자라는 모습 4단계 → 수확. 사흘 마르면 시듦, 제철 아니면 수확량 적음
- 형사님과 함께 심기 · 물 주기 · 수확(대사 · 호감도), 수확물 선물, 결혼 후엔 형사님이 아침에 물을 줌, 첫 수확 앨범
- 아이콘: 도트 아이콘 대신 컬러 이모지. 흑백으로 나오던 기호는 컬러 표시로 바꾸거나 비슷한 컬러 이모지로 교체 (물고기 도감은 종류 구분용 도트 유지)

- 장소 활동에서 다른 메뉴와 겹치던 항목(사진 찍기 · 가구 정리 · 카페 데이트 · 소풍 · 행사 보기) 정리, 같은 활동이 두 번 뜨던 버그 수정

- 오른쪽 위 지도 · 퀘스트 버튼을 같은 크기로 나란히, 첫 화면 버튼 위로
- 지도 깜빡임 수정: 확대 시 휴대폰 캔버스 한계를 넘던 해상도 제한, 두 손가락 확대 중엔 다시 그리지 않음
