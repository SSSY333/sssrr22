# 해월도 마을생활 (Alpha 0.1)

쿼터뷰 섬마을 생활 시뮬레이션 + 연애 게임. 다섯 직업 중 하나로 해월도에서 지내면서
**파출소 형사님**과 만나고, 함께 걷고, 앉고, 낚시하고, 데이트하며 관계를 키워 갑니다.
모바일 세로 화면에 맞췄고, 캐릭터·건물·지형은 모두 코드로 한 픽셀씩 그린 픽셀아트입니다 (외부 이미지 없음).

## 실행
빌드가 필요 없는 정적 페이지입니다.

```bash
cd haewoldo
python3 -m http.server 8000
# http://localhost:8000 (같은 Wi-Fi 휴대폰에서는 http://<PC IP>:8000)
```

| | 휴대폰 | PC |

## Alpha 0.1 구현 범위
1. **파출소 형사님 NPC** — 키 크고 어깨 넓은 SD 캐릭터, 근무복(남색 제복·배지) / 퇴근 후 평상복(소매 걷은 셔츠)
2. **자율 일과** — 07시 출근 → 오전 마을 순찰 → 12시 카페 벤치 점심 → 파출소 → 15시 부두 순찰 → 17시 퇴근 산책 → 19시반 부두 낚시 → 22시 귀가
3. **직업별 첫 만남** — 의사(다친 할머니를 업고 옴), 선생님(등굣길 순찰), 여행객(날아간 지도), 카페 사장님(개업 첫 손님), 해녀(너울 경고)
4. **대화와 선택지** — 단계별 대화 주제, 선택에 따라 다른 대답·표정(초상화 8종)·호감도
5. **호감도와 6단계 관계** — 대화 버튼을 반복해서는 오르지 않음 (하루 대화 2회까지만 호감도). 함께 보낸 시간, 활동, 선택, 이벤트 완료가 조건
6. **함께 다니기** — 형사님이 플레이어가 걸어온 길을 따라오고, 멈추면 옆자리에 섬. 가만히 있으면 두리번거리거나 말을 검. 근무 중에는 90분 제한, 밤에는 거절
7. **함께 앉기** — 카페 테라스 · 부두 · 등대 · 언덕 전망대 벤치, 장소 × 관계 단계별 대사
8. **이벤트** — 첫 만남, 첫 산책, 나란히 앉은 시간, 부두에서 기다려 준 사람, 야간 순찰 중 우연히, 우산 하나 두 사람(비 오는 날), 고백(수락 · 보류 · 거절 모두 가능, 플레이어가 먼저 고백도 가능)
9. **연인 콘텐츠(5단계)** — 데이트 8곳, 손잡기 · 팔짱 · 안아주기 · 머리 쓰다듬기, 사진 찍기
10. **추억 앨범** — 이벤트 순간을 픽셀 스냅샷으로 날짜 · 장소와 함께 저장
11. **마을생활** — 직업 일하기(돈 · 직업 레벨), 마을 슈퍼(선물 구입 · 해산물 판매), 낚시 미니게임, 주민 3명, 날씨(맑음 · 흐림 · 비), 낮/노을/밤 조명과 등대 불빛
12. **자동 저장** — 15초마다, 이벤트 직후, 앱을 내릴 때 `localStorage`에 저장. 이어하기 시 위치 · 시간 · 관계 · 이벤트 진행 · 동행 상태 · 앨범 복원

## 파일
- `index.html` — 화면 구조 (HUD, 대화창, 메뉴 시트, 관계 화면, 타이틀)
- `style.css` — 모바일 세로 UI
- `js/sprites.js` — 픽셀아트 생성기 (SD 캐릭터, 초상화 표정, 타일, 소품, 건물)
- `js/world.js` — 섬 지도, 건물 · 벤치 · 장소, A* 길찾기
- `js/content.js` — 직업, 관계 단계, 아이템, 대사 · 이벤트 텍스트
- `js/game.js` — 엔진 (렌더링 · 깊이 정렬, 형사님 AI · 동행, 이벤트, UI, 저장)

브라우저 콘솔의 `HW` 객체로 상태를 볼 수 있습니다 (예: `HW.S.rel`).
