# 보장원 (2D 도트 멀티플레이 오피스)

광화문 세종대로의 유리 빌딩 **보장원**에 내 도트 캐릭터로 들어가 돌아다니는 2D 웹 게임입니다.
그림·음악·효과음을 모두 코드로 한 칸 한 칸 찍고 합성해서, 외부 그림·음원 파일이 없어요 (글꼴만 따로 들어 있어요).

> 예전 three.js 3D 버전은 [`3d.html`](3d.html)에 그대로 남아 있어요 (3D와 2D는 서로 다른 방이에요).

## 들어가기
1. 닉네임을 쓰고 도트 캐릭터 5종(비니 · 안경 긴 머리 · 카디건 · 정장 · 헤드폰) 중 하나를 고릅니다.
2. **입장하기**를 누르면 보장원 정문 앞 인도에서 시작해요. 닉네임과 캐릭터는 이 브라우저에 기억돼요.

## 조작
| | 데스크톱 | 휴대폰 |
| --- | --- | --- |
| 이동 | 방향키 / WASD, 화면을 누르면 그 자리까지 길을 찾아 걸어가요 | 왼쪽 아래 조이스틱, 화면 누르기 |
| 행동 (앉기·눕기·할 일·일어나기) | Space / E, 오른쪽 아래 노란 버튼 | 오른쪽 아래 노란 버튼, 물건 누르기 |
| 말하기 | 💬 대화하기 (T) → 문구 고르기 | 💬 대화하기 |
| 콕 찌르기 | 다른 사람 클릭, Q | 다른 사람 누르기 |
| 장소 이동 · 캐릭터 바꾸기 · 사진 · 음악 | 🧭 · 👕 · 📷 · 🎵 | 같아요 |

## 지도
동선은 3칸(1.5 m) 이상 넓게 잡았고, 가구·물건은 서로 겹치지 않아요. 자동 검사로 매번 확인해요 (아래 '검사').

- **보장원 1층**
  - 업무공간: 4인 책상 섬 6개(24석), 위쪽 벽에 포스터 4장(오늘도 수고했어요 · 점심 투표 · 체육대회 · 공지 — '🔍 포스터 보기'로 크게), 벽시계(서울 시각).
  - 회의실: 6인 회의 테이블, 발표 화면, 화이트보드.
  - 프린터실: 프린터 3대(정상 출력 / 종이 걸림 / 폭주), 파쇄기.
  - 불만창고: 벽난로, 큰 곰 인형(꼭 안아주기), 빈백 2개.
    - 🔥 스트레스 태우기 → 적은 종이를 벽난로에 던져요. **내용은 저장되지도, 누구에게 보내지지도 않아요.** 다른 사람에게는 종이가 날아가 불꽃이 확 타오르는 모습만 보여요.
  - 탕비실: 커피 머신(☕ 내리면 컵을 들고 다녀요), 싱크대 물, 간식장, 냉장고, 스탠딩 테이블.
  - 수면실: 침대 8개(눕기 → 이불 덮고 Zzz), 커튼, 무드등.
  - 라운지: 소파, 빈백, 탁구대(🏓 탁구 치기), 책장(📖 책 꺼내 읽기).
  - 로비 · 홀: 넓게 비워 둔 공간, 벤치, 큰 화분, 자동문.
- **바깥**
  - 광화문 거리: 은행나무, 가로등, 횡단보도 2곳(사람이 차 앞에 있으면 차가 멈춰요), 중앙 화단과 동상, 버스 정류장.
  - 광화문, 아래쪽 공원(벤치).
  - 맛집 거리: 광화문 빵집 · 세종 떡볶이 · 은행나무 커피 · 달콤 디저트 · 광장 피자 — 🛍️ 주문하면 음식을 들고 다녀요. 가게 앞 테라스에 앉을 수 있어요.
- **고양이 4마리**: 시계로 계산되는 길을 걸어서 모든 접속자에게 같은 곳에 보여요. 🐱 쓰다듬기 → 하트.
- **서울 시간 반영**: 낮 · 노을 · 밤에 따라 바깥 색이 바뀌고, 밤에는 가로등과 가게 창문이 켜져요.

## 멀티플레이
- **GitHub Pages 등 일반 웹 주소**: 가입이 필요 없는 무료 공개 MQTT 중계소(HiveMQ · EMQX) 두 곳에 동시에 보내고 받아요. 휴대폰 데이터 · 다른 브라우저 사이에서도 연결돼요.
  - 테스트용 공개 서비스라 가끔 느리거나 멈출 수 있고, 닉네임·위치·말풍선은 누구든 마음먹으면 볼 수 있어요 (불만창고 내용은 보내지 않아요).
  - 위치는 1초에 약 7번 보내고, 받은 쪽은 속도로 '지금쯤 여기 있겠지'를 예측해 부드럽게 따라가요.
- **지연 확인**: 게임 왼쪽 위 '👥 n명'을 누르면 네트워크 상태 창이 열려요. [`loadtest.html`](loadtest.html)에서 봇 5→50명으로 지연·손실을 잴 수 있고, '실제 방에 봇 넣기'를 켜면 봇이 맛집 거리 앞 인도를 걸어 다녀요.
- **claude.ai 아티팩트**: 아티팩트의 `room` 기능으로 연결돼요.

## 음악 · 효과음 (브라우저가 직접 연주)
옛날 게임기 같은 8비트 소리예요. 구역마다 곡이 달라요 — 사무실 · 라운지 · 수면실(잔잔하게) · 불만창고 · 거리 · 맛집 거리. 4마디가 끝날 때 다음 곡으로 넘어가요.
효과음: 말풍선 '뽁', 콕 찌르기 '삐용~', 커피 내리기, 와삭와삭, 프린터, 파쇄기, 종이, 벽난로 '화르륵', 곰 인형 포옹, 탁구공.

## 검사
- 가구끼리 바닥 영역·그림이 겹치는지, 의자 자리가 벽에 걸리는지, 정문에서 모든 자리·할 일·이동 장소까지 걸어갈 수 있는지 자동으로 확인해요 → 겹침 0, 못 가는 곳 0.
- 두 창을 띄워 서로 보이는지 · 콕 찌르기 · 앉기가 맞게 전달되는지 확인했어요.
