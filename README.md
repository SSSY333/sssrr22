# 보장원 (three.js 3D 멀티플레이 웹페이지)

광화문 세종대로의 유리 빌딩 **보장원**에 내 캐릭터로 들어가 돌아다니는 3D 웹페이지입니다.

## 들어가기
1. 닉네임을 쓰고 캐릭터 5종 중 하나를 고릅니다. 성별 구분은 없어요.
2. **회사로 들어가기**를 누르면 횡단보도 앞에서 시작해 자동문을 지나 로비로 걸어 들어갑니다.
   닉네임과 캐릭터는 이 브라우저에 기억돼요.

## 할 수 있는 것
- **광화문 거리 걷기**: 인도와 중앙 광장, 횡단보도로만 건널 수 있어요 (건너는 중엔 차가 멈춤).
- **맞은편 맛집 거리**: 칼국수 · 빵집 · 떡볶이 · 카페 · 디저트 · 고깃집 · 브런치 · 피자 · 국밥 · 젤라토 가게 10곳. 줄무늬 차양, 불 켜진 간판과 진열창, 오늘의 메뉴 입간판, 줄조명. 테라스 의자(28석)에 앉으면 '맛있겠다! 😋' 같은 대사 버튼이 떠요.
- **길고양이 7마리**: 치즈 · 고등어 · 까망(흰 양말) · 하양 · 삼색 · 턱시도 · 갈색 줄무늬. 인도·중앙 광장·맛집 거리의 자기 영역을 걸어 다니다가
  아무 데서나 웅크리거나(식빵 자세), 그루밍하거나, 동그랗게 잠들어요. 시계로 계산되는 일정이라 모든 접속자에게 같은 곳에 보여요.
  가까이 가서 **🐱 쓰다듬기**를 누르면 눈을 감고 골골송과 함께 하트가 떠올라요 (다른 사람에게도 쓰다듬는 모습이 보여요).
- **실제 시간 반영**: 서울 시각에 맞춰 하늘색 · 해와 달 · 별 · 안개 · 반사광 · 창문 불빛 · 가로등이 바뀌어요 (새벽 · 낮 · 노을 · 해 질 녘 · 밤). 왼쪽 위에 시각이 보여요.
- **포스터 벽**: 업무공간 뒷벽 벽돌에 포스터(오늘도 수고했어요 · 점심 투표 · 체육대회 · 공지)를 벽 그림과 한 장으로 합쳐 반듯하게 붙였어요.
- **수면실 무드등**: 종이 등 펜던트, 플로어 스탠드, 달 모양 협탁등, 침대 밑 은은한 빛.
- **회의실** (업무공간 안쪽 왼쪽 구석): 유리벽, 8인 회의 테이블, 발표 화면. 회의 자리에 앉으면 회의 대사 버튼이 떠요.
- **탕비 코너** (왼쪽 창가): ☕ 커피 뽑기(원두 가는 소리 → 졸졸 → 띵) 후 컵을 들고 다니다 '☕ 한 모금' 마시기, 🗑️ 쓰레기통에 컵 버리기, 🍪 간식·🍎 사과 먹기(와삭와삭). 휴게실 주방 커피 머신·과일 바구니도 같아요.
- **프린터 3대**: 출력하면 무작위로 정상 출력 / 종이 걸림(빨간불 깜빡깜빡) / 폭주(종이가 사방으로 날아감).
- **파쇄기**: 종이를 넣으면 갈갈갈 소리와 함께 종잇조각이 통에 쌓여요.
- **책상 스탠드**: 모든 책상에 스탠드.
- **다채로운 책상**: 모든 책상이 소품(화분·선인장·곰인형·고무오리·고양이·액자·트로피·책·꽃병), 모니터 화면, 머그컵·의자 색으로 제각각 꾸며져 있어요.
- **업무공간**: 의자에 앉아 타자 치며 일하기 (24석).
- **휴게실**: 원형 쇼파에 둘러앉기(10석), 빈백, **탁구 치기**(양쪽 2명).
- **수면실**: 침대 4개에 눕기, 리클라이너, 빈백.
- **불만창고** (로비 왼쪽 구석, 반짝이 커튼 안): 하트·별 벽지, 꼬마전구, 별빛 천장, 떠다니는 반짝이, 타닥타닥 벽난로, 곰인형(큰 곰인형은 꼭 안을 수 있어요).
  - ✍️ 책상에 앉아 **스트레스 적기** → 🔥 벽난로에 던지면 구겨진 종이가 날아가 불꽃이 확 타올라요.
  - 🎋 대나무숲 구멍 앞에서 **임금님 귀는 당나귀 귀** → 쓴 만큼 오래, 빨개진 얼굴·💢·김·부들부들과 함께 `#@$%&!!` 말풍선으로 마구 외쳐요.
  - 🔒 여기 쓴 내용은 어디에도 저장·전송되지 않고 버튼을 누르는 즉시 지워져요. 다른 사람에게는 종이 던지기·화난 모습 같은 동작만 보여요.
- 하는 일마다 그에 맞는 **대사 버튼**이 떠요. 무작위가 아니라 내가 고른 대사가 말풍선으로 나와요.
- **콕 찌르기**: 채팅창은 없어요. 다른 사람을 누르면 찌른 사람과 찔린 사람에게 각각 무작위 대사가 나와요.

## 물리
- 캐릭터는 원(반지름 0.28 m)으로 벽·가구·나무·가로등·차도와 충돌하고, 좁은 틈에서 겹칠 것 같으면 그 이동은 막아요.
- 높이는 바닥(실내 · 인도 · 횡단보도)에 붙어 있어 공중에 뜨거나 바닥 밑으로 빠지지 않아요.
- 무작위로 30,000걸음 걸어 보는 자동 테스트에서 겹침 0, 벽 통과 0, 바닥 이탈 0.

## 멀티플레이
- **GitHub Pages 등 일반 웹 주소**: 가입이 필요 없는 무료 공개 MQTT 중계소(HiveMQ · EMQX) 두 곳에 동시에 보내고 받아요.
  휴대폰 데이터·회사 와이파이·서로 다른 브라우저(크롬 ↔ 삼성 인터넷)에서도 연결돼요. 한 곳이 멈춰도 다른 곳으로 계속돼요.
  - 테스트용 공개 서비스라 가끔 느리거나 멈출 수 있고, 지나가는 닉네임·위치·말풍선은 누구든 마음먹으면 볼 수 있어요 (불만창고 내용은 보내지 않아요).
  - 처음엔 브라우저끼리 직접 연결(Trystero/WebRTC)을 썼지만, 휴대폰 통신망·다른 브라우저 사이에서 직접 연결이 막혀(TURN 서버 없음) 바꿨어요.
- **지연 확인**
  - 게임 왼쪽 위 '👥 n명'을 누르면 네트워크 상태 창이 열려요. 중계소 연결 상태, 사람마다 왕복 지연(창을 연 동안 2초마다), 1초에 받는 소식 횟수가 보여요.
  - [`loadtest.html`](loadtest.html): 봇을 5→50명까지 늘리며 중계소 지연·손실을 재는 페이지. '실제 방에 봇 넣기'를 켜면 봇이 게임 속 건물 앞 인도를 걸어 다녀요.
- **claude.ai 아티팩트**: 아티팩트의 `room` 기능으로 연결돼요.

## 도트 보장원 (`pixel/`)
보장원 3D와 같은 내용을 해월도·개금역처럼 쿼터뷰 2D 도트 게임으로 옮긴 버전이에요. 파일 하나(`pixel/index.html`)이고, 그림·음악은 모두 코드로 한 픽셀씩 그려요 (외부 이미지 0개).
- 같은 장소: 광화문 거리(횡단보도로만 건너기, 사람이 있으면 차가 멈춤) · 광화문 · 맞은편 맛집 거리 10곳(차양·간판·오늘의 메뉴 입간판·테라스 24석) · 로비 · 업무공간 24석(포스터 벽, 책상마다 다른 소품·화면·머그·의자) · 회의실 8석 · 탕비 코너 · 휴게실(원형 쇼파 10석, 빈백, 탁구) · 수면실(침대 4, 리클라이너, 무드등) · 불만창고
- 같은 놀이: 커피 뽑기 → 한 모금 → 컵 버리기, 간식·사과, 프린터 3대(정상 / 종이 걸림 / 폭주), 파쇄기, 길고양이 7마리 쓰다듬기(시계로 계산해 모두에게 같은 곳), 콕 찌르기, 장소별 대사 버튼, 캐릭터 5종 바꾸기, 사진 찍기, 서울 시각에 맞춘 새벽·낮·노을·해 질 녘·밤
- 불만창고: 스트레스 적기 → 벽난로에 던지기, 대나무숲에 마구 외치기, 곰인형 안기. 적은 내용은 저장·전송하지 않고 바로 지워요.
- 장소·시간별 배경음악 8곡과 효과음을 브라우저가 직접 연주해요.
- 멀티플레이는 claude.ai 아티팩트의 `room` 기능으로 연결돼요 (GitHub Pages에서는 혼자 모드).
- 조작: 방향키/WASD 이동, Shift 달리기, 바닥·의자·사람·고양이를 누르면 그쪽으로 가서 행동, E/Space 행동, 숫자키 1~9 대사, 휠·두 손가락으로 확대

## 휴대폰
- 세로 화면에서는 시야각을 넓히고, 픽셀 비율·그림자 해상도를 낮추고 블룸을 꺼서 가볍게 동작

## 실행
빌드가 필요 없는 정적 페이지입니다. three.js는 CDN(jsdelivr, `three@0.170.0`)에서 불러옵니다 (용량 계산에서 제외).

```bash
python3 -m http.server 8000
# http://localhost:8000 접속 (같은 Wi-Fi의 휴대폰에서는 http://<PC IP>:8000)
```

GitHub Pages: 저장소 Settings → Pages → Source를 'Deploy from a branch', 브랜치를 이 브랜치 / (root)로 저장하면 `https://sssy333.github.io/sssrr22/` 에서 열려요.

## 파일
- `index.html` — 페이지 구조, 입장 화면, 하단 내비게이션
- `style.css` — UI 스타일 (safe-area 대응)
- `main.js` — three.js 씬 전체 (거리, 빌딩, 실내, 캐릭터, 이동·충돌, 좌석, 멀티플레이, 사운드)
- `assets/` — CC0 스캔 모델(.glb), PBR 텍스처(.webp), HDRI(.exr)
