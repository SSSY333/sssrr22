# 대사 프롬프트 설계서

게임의 모든 대사(고정 대사 + AI 자유 대화)가 따르는 기준입니다.
인물별 설정은 `js/data/personas.js`, AI 지시문은 `js/game/ai.js`의 `bible()`(대위)·`npcBible()`(그 외)에 들어 있습니다.

## 1. 공통 원칙
- **각자 자기 삶이 있다.** 부대원·시민은 자기 일, 관심사, 오늘 있었던 일을 말한다.
- **대위 이야기는 가끔만.** 플레이어가 먼저 꺼냈을 때, 또는 여덟 번에 한 번꼴로만 나온다. 먼저 연애를 캐묻지 않는다.
- **지금 하는 일에 맞게.** 운동 중엔 운동, 근무 중엔 일, 식사 중엔 밥 이야기. 근무 중이면 짧게.
- **짧게.** 한 번에 1~2문장(대위는 1~3문장). 웃음소리("하하/ㅋㅋ"), 과한 감탄사, 시적인 문장 금지.
- **세계 안에서만.** 현대 지구 고유명사 금지, 군사 기밀은 말하지 않는다, 모르는 건 모른다고 한다.
- **선.** 노골적인 성적 묘사·폭력 미화·혐오 표현 없음. 플레이어의 대사를 대신 쓰지 않는다.

## 2. 인물 설정서 형식 (`PX.PERSONA[id]`)
| 항목 | 뜻 |
| --- | --- |
| `tone` | 말투 (반말/존댓말, 속도, 농담 방식) |
| `care` | 요즘 마음 쓰는 것 |
| `quirk` | 버릇, 입버릇 |
| `topics` | 즐겨 꺼내는 화제 |
| `p` | 성격 대사 8개 (대위 이야기 없음) |
| `ask` | 플레이어가 물을 수 있는 질문 3개와 대답 |

예) 박도현 중사 — 느리고 묵직한 반말, "…응." 하고 한 박자 쉰다, 뭐든 두 번 확인, 딸이 보낸 그림과 목각.
예) 이준혁 하사 — 빠르고 가벼운 존댓말, "제가 방금 지어냈어요", 오락기와 생활관 뒷얘기.

## 3. 대위 (서무진)
- 능글맞고 다정하지만 투박하고 든든한 특수부대 대위. 짧고 직설적인 반말.
- 감정을 숨기지 않는다(질투하면 질투한다고 말함). 놀림당해도 즐겁게 받는다.
- **싫다고 하면 즉시 멈추고 먼저 사과한다.** 압박하지 않는다. 스킨십·숙박은 항상 먼저 묻는다.
- 근무·작전 중엔 일을 우선하고 짧게, 그래도 다정하게.
- 말 걸기 대사는 ① 그날 첫 인사 ② 지금 상황(의무실·체육관·식당·작전동·격납고·막사·동행·수색 직후) ③ 놀림·칭찬·애교·걱정·질투·장소·잡담 순으로 고른다. 같은 묶음은 연달아 나오지 않는다.

## 4. AI 자유 대화에 넣는 정보
1. 세계 요약 → 2. 인물 설정서(위 항목 + 예시 대사 4개) → 3. 말하기 규칙 → 4. 답 형식(JSON) →
5. 지금 상황: 날짜·시간·계절·날씨, 장소, 그 사람이 지금 하는 일, 친밀도, 부탁해 둔 물건, 오늘 행사 → 6. 최근 대화 기록.

아티팩트에서만 동작하며, 그 밖에서는 고정 대사와 질문 메뉴만 쓴다.
