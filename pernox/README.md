# 사랑해, 이 행성이 멸망할 때까지. — Alpha 0.2

제5행성 페르녹스 · 지구군 606부대를 무대로 한 **쿼터뷰 SD 도트 생활 · 연애 시뮬레이션** (HTML5 모바일 웹 + 안드로이드 APK).
모든 그림은 외부 이미지 없이 캔버스 코드로 직접 찍습니다. 외부 AI API는 쓰지 않고, 대사는 고정 대사 + 선택지입니다.

## 실행
| 방법 | 파일 |
| --- | --- |
| 개발용 (파일 분리) | `pernox/index.html` 을 브라우저로 열기 |
| HTML 한 파일 | `pernox/dist/pernox.html` (글꼴까지 포함, 약 870 KB, 인터넷 없이 실행) |
| 안드로이드 | `pernox/dist/pernox-0.2.0.apk` (WebView, 디버그 서명, Android 7.0+) |

빌드: `node tools/build.js` (한 파일 HTML) · `tools/build-apk.sh` (APK, Android SDK build-tools 35 필요)

## 조작
- 휴대폰: 화면을 누르면 그곳으로 걸어감(길찾기). 사람·가구·문을 누르면 다가가서 상호작용. 아래 노란 버튼 = 가까운 대상과 행동.
- PC: 방향키/WASD 이동, Shift 달리기, E·Space 행동, T 단말, 숫자키로 선택지, Esc 닫기.
- 오른쪽 버튼: 📟 개인 단말 · 📷 사진 찍기(사진첩) · 🛋️ 숙소 꾸미기(숙소 안에서만).

### 시간 · 달력
- 현실 1초 = 게임 1분 (설정에서 느림 2초 / 빠름 0.5초). 대화창·메뉴·미니게임·캐릭터 생성 중엔 멈춤.
- 그레고리력 직접 계산: 1990~2110년 44,194일을 JS `Date`와 대조해 요일·월 일수 불일치 0. 윤년 규칙(4·100·400) 적용.
- 시작 날짜 선택 가능(기본 2027-01-01, 금). 계절 3~5 봄 / 6~8 여름 / 9~11 가을 / 12~2 겨울.
- 날씨는 날짜로 결정(맑음·흐림·비·붉은 모래바람·은빛 눈·발광포자 바람). 돔시티는 인공 기후.

### 로어북
LB01~LB89 전 항목이 16개 필드(id, originalTitle, keywords, description, location, season, months, weekdays, startTime, endTime, accessCondition, eventType, interactions, captainReaction, rewards, repeatRule)로 등록됨.
반복 규칙(n번째 요일, 마지막 금요일, 둘째 주말, 매월 1·15·말일 등)을 실제 달력으로 계산해 일정표·안내 단말·NPC 대사에 나옵니다.

### 저장
슬롯 2개. 지금 쓰는 슬롯에 자동 저장(장소 이동·잠·5분마다·앱이 백그라운드로 갈 때) + 단말에서 수동 저장. 저장 버전(v2)과 이전 버전 변환 함수 포함.

- NPC 24명 전원 배치·일과 이동(평일/주말, 식사 시간엔 식당에 모임, 밤엔 생활관에서 잠), 사람마다 고정 대사·좋아하는 음식/선물·관계값
- **대위**: 전용 큰 스프라이트(검은 머리, 코 흉터, 나시 + 열린 위장 재킷, 인식표, 여름엔 나시만), 하루 일과(기상·체력단련·식사·브리핑·장비 점검·외곽 수색·복귀 검진·개인 시간·취침)
  - 근무·작전 중엔 따라오지 않음 → 근무 끝나면 플레이어를 찾아와 먼저 말을 걸고 동행 제안
  - 동행(속도 맞춰 걷기, 끼이면 길 다시 찾기), 손잡고 걷기, 앉으면 옆자리 차지, 식당 옆자리
  - 내 숙소에 있으면 **문 앞에서 기다리다 노크** → 들어오게 하기 / 나가서 만나기 / 쉬고 싶다고 하기
  - 방문 중 밤이 되면 능청스러운 **숙박 요청**(냉각기 고장 핑계 등) → 허락하면 소파(연인부터는 침대도)에서 자고 아침 대사, 거절하면 아쉬워하며 돌아감
  - 플레이어가 잠들면 허락 없이 머물지 않음. "혼자 있고 싶어요"를 고르면 다음 날 아침까지 찾아오지 않음
  - 떨어져 있을 때 메시지(외곽 수색 중엔 수색지 메시지), 외곽에서 주운 돌·간식 선물, 문틀에 머리 박기
- 고정 대사: 대위 대사 카테고리 20개 이상(인사·아침·점심·퇴근·심야·근무 중·장난·칭찬·애교·유혹·노골적 애정·질투·걱정·위로·데이트 신청·스킨십·사과·화해·숙소 방문·숙박 요청 …), 주요 카테고리마다 10묶음 이상. 관계 단계·시간·날씨·직업·행사 조건 반영, 최근 4일 안에 쓴 묶음은 다시 안 나옴
- 장난·유혹 대사엔 늘 **"그런 말은 좀 싫어요"** 선택지 → 대위가 사과하고 다음 날까지 장난 멈춤 (호감 감소 없음)
- 관계 8단계 (아는 사이 → 친한 사이 → 썸 → 고백 직전 → 연인 → 깊어진 사랑 → 약혼 → 부부), 고백 이벤트(수락·보류·거절)
- 스킨십: 손잡기, 팔짱, 머리 쓰다듬기, 포옹, 볼 입맞춤, 입맞춤, 업기 — 단계 제한, 언제든 거절 가능
- 직업별 근무(평일 09~12시, 13~17시) **미니게임 4종**: 군의관 상처 치료 · 수색 소위 드론 정찰 · 정비 중위 회로 연결 퍼즐 · 연구원 검역 분류 → 점수에 따라 급여
