# 사랑해, 이 행성이 멸망할 때까지. — Alpha 0.2

제5행성 페르녹스 · 지구군 606부대를 무대로 한 **쿼터뷰 SD 도트 생활 · 연애 시뮬레이션** (HTML5 모바일 웹 + 안드로이드 APK).
모든 그림은 외부 이미지 없이 캔버스 코드로 직접 찍습니다. 외부 AI API는 쓰지 않고, 대사는 고정 대사 + 선택지입니다.

## 실행
| 방법 | 파일 |
| --- | --- |
| 개발용 (파일 분리) | `pernox/index.html` 을 브라우저로 열기 |
| HTML 한 파일 | `pernox/dist/pernox.html` (글꼴까지 포함, 약 870 KB, 인터넷 없이 실행) |
| 안드로이드 | `pernox/dist/pernox-0.2.0.apk` (WebView, 디버그 서명, Android 7.0+) |

빌드: `node tools/build.js` (한 파일 HTML) · `tools/build-apk.sh` (APK, Android SDK build-tools 35 필요)

## 조작
- 휴대폰: 화면을 누르면 그곳으로 걸어감(길찾기). 사람·가구·문을 누르면 다가가서 상호작용. 아래 노란 버튼 = 가까운 대상과 행동.
- PC: 방향키/WASD 이동, Shift 달리기, E·Space 행동, T 단말, 숫자키로 선택지, Esc 닫기.
- 왼쪽 아래 조이스틱(끝까지 밀면 달리기), 오른쪽 ＋/－ 확대·축소.
- 오른쪽 버튼: 📟 개인 단말 · 📷 사진 찍기(사진첩) · 🛠️ 맵 편집(어느 맵에서나: 끌어서 옮기기·회전·치우기·추가·되돌리기, 저장됨).
- 의자·벤치·소파·침대는 눌러서 언제든 앉기/눕기.
- 대위가 가까우면 오른쪽 아래에 💬(대위 메뉴)·🤝(스킨십) 버튼, 주변 대상이 여럿이면 ⋯ 버튼으로 골라서 상호작용. 동행 중엔 위쪽 대위 칩을 눌러 동행 관리.

### 시간 · 달력
- 현실 1초 = 게임 1분 (설정에서 느림 2초 / 빠름 0.5초). 대화창·메뉴·미니게임·캐릭터 생성 중엔 멈춤.
- 그레고리력 직접 계산: 1990~2110년 44,194일을 JS `Date`와 대조해 요일·월 일수 불일치 0. 윤년 규칙(4·100·400) 적용.
- 시작 날짜 선택 가능(기본 2027-01-01, 금). 계절 3~5 봄 / 6~8 여름 / 9~11 가을 / 12~2 겨울.
- 날씨는 날짜로 결정(맑음·흐림·비·붉은 모래바람·은빛 눈·발광포자 바람). 돔시티는 인공 기후.

### 로어북
LB01~LB89 전 항목이 16개 필드(id, originalTitle, keywords, description, location, season, months, weekdays, startTime, endTime, accessCondition, eventType, interactions, captainReaction, rewards, repeatRule)로 등록됨.
반복 규칙(n번째 요일, 마지막 금요일, 둘째 주말, 매월 1·15·말일 등)을 실제 달력으로 계산해 일정표·안내 단말·NPC 대사에 나옵니다.

### 저장
슬롯 2개. 지금 쓰는 슬롯에 자동 저장(장소 이동·잠·5분마다·앱이 백그라운드로 갈 때) + 단말에서 수동 저장. 저장 버전(v2)과 이전 버전 변환 함수 포함.

## 1.0 정식버전 — 대위 행동·대화·스킨십·동행·장기작전 전면 개선
- **단기 기억** (`js/game/capmind.js`): 마지막 대화·만남·헤어짐 시각, 장소·주제, 마지막 스킨십, 현재 접촉, 거절한 행동, 최근 대사·행동, 그리움. 대화·이동·스킨십·동행·메시지가 모두 같이 본다
  - 경과 시간별 인사: 0~2분 이어서 말하기 · 2~15분 가벼운 추가 · 15~60분 재접촉 · 1~6시간 반가움 · 6~24시간 보고 싶었다 · 1일 이상 오랜만 · 장기작전 뒤 재회. 방금 대화한 사람에게 "오랜만", "어디 갔다 왔어" 금지
  - 헤어지면 30분 동안 따라오거나 부르지 않음(먼저 말 거는 건 언제든), 거절한 동행·숙소 방문·스킨십은 한동안 다시 묻지 않음, "보고 싶어·귀여워·안아 줄까" 같은 표현은 45분 쉬게
- **접촉 상태 머신**: 접촉 없음 · 손잡기 · 팔짱 · 허리 · 어깨 · 옆/정면/백허그 · 품에 안기 · 무릎베개 · 누워서 껴안기 · 함께 잠들기. 이미 하고 있는 건 메뉴에서 숨기고, 전환할 땐 이전 자세를 끝내고 다음 자세로. 걷기 시작하면 포옹은 자연스럽게 풀림. 접촉마다 팔 그림이 다름(체격 차이 반영)
- **스킨십 50여 종** (조건·결과 상태·쿨다운·대사 묶음): 손깍지·손등 입맞춤·앞머리 정리·이마 맞대기·코끝·볼 꼬집기·귓속말·머리 위 턱·백허그·안고 흔들기·어깨에 얼굴 묻기·이마/관자놀이/볼/코/입술 입맞춤·옆에 바짝 앉기·어깨에 기대기·무릎베개·팔베개·누워서 껴안기·마사지·이불 덮어 주기 … 침대 행동은 연인 이상, 같은 방에서만. 대위가 먼저 원할 땐 묻고, 거절하면 4시간 동안 같은 건 안 물음
- **표정·행동 반응**: 웃으며 바라보기 · 빤히 보기 · 부끄러워하기 · 삐진 척 · 피곤한 티 → 각각 15~18개 능글맞은 반응. 멈춰 서서 대위를 계속 바라보면 대위가 먼저 말을 걸음
- **장소별 반응**: 숙소 앞(들어가도 돼? / 차 한 잔만 / 오늘은 여기까지), 샤워실(밖에서 기다리다 나오면 다시 동행), 루비웨이, 대위 막사, 카페·냉삼집·관광지·여행
- **동행 UI**: 동행·손잡기 중에도 건물 입장·상점·다른 NPC·의자·지도 모두 사용. 기본 버튼은 대위가 아닌 대상 우선, 대위는 💬·🤝 전용 버튼, 대상이 여럿이면 ⋯ 버튼으로 목록. 위쪽 대위 칩에 접촉 아이콘, 누르면 동행 관리(함께 걷기·손잡기·팔짱·허리·어깨·잠깐 기다리기·종료, 지금 상태는 '사용 중')
- **장기작전** (`js/game/longop.js`): 열흘에 한 번꼴, 이틀 전 예고. 수색팀 소위는 함께 투입(수송선 → 브리핑 → 야영지 → 장비 점검 → 흔적 조사 → 경계 근무 → 식사 → 야간 대화 → 함께 귀환), 군의관·정비 25%, 민간 연구원은 승인된 공동 조사(12%)일 때만. 혼자 갈 땐 단말로 하루 2~4번 연락(그리울수록 자주), 통신 두절이면 밀렸다가 한꺼번에, 도트 셀카·풍경·광물·단체·식사 사진. 복귀 땐 도착 → 보고 → 장비 반납 → 의료 확인 → 샤워 → 찾아와 재회 + 선물
- **정식 관계 콘텐츠** (`js/game/romance.js`): 데이트 약속(장소·날짜·시간, 2시간 전 알림, 대위가 먼저 가서 기다림, 못 가면 탓하지 않는 메시지), 휴가 신청(대위도 맞춰 쉴 수 있음), 축제 당일 연출(불꽃), 프러포즈(대위가 직접 깎은 반지 / 플레이어가 반지를 건넬 수도), 약혼, 연병장 결혼식(강태욱 중령 주례, 부대원 참석), 동거, 기념일(연인 100·200·300·365일, 결혼기념일)
- **대사 추가**: 경과 시간 7종 × 15, 접촉 중 4종 × 15, 표정 반응 5종 × 15~18, 장소·작별·데이트 종료·잠들기 전·다음 날 아침·장기작전 전/합동/복귀·기념일 각 15 내외. 능글맞은 대사 묶음 150개 이상
- **가볍게**: 느린 폰은 자동 절전(30fps · 군중 절반 · 빛 번짐 끔), 조명 그림 재사용, 설정에 화질(자동·고화질·절전). 쓰지 않던 코드(옛 스킨십 요청·중복 술 마시기·개발용 확인 페이지) 삭제

## Alpha 0.5 — 전체 점검 반영
- **사람 통과 방지**: 플레이어가 서 있는 사람을 뚫고 지나가지 않음. 길을 막은 사람은 옆으로 비켜 줌. NPC 길찾기도 사람이 선 칸을 돌아감. 한 칸에 겹쳐 선 사람은 자동으로 떼어 놓음 (57개 맵 × 여러 시간대 자동 검사: 벽·가구 안에 선 사람 0, 겹친 사람 0)
- **그래픽**: 키 큰 가구(냉장고·거치대·자판기·책장 등) 뒤에 가려지던 창문·포스터·화면을 빈 벽으로 자동 이동. 외곽 "미확인 동굴"을 창문 달린 집 → 바위 언덕과 동굴 입구로
- **문맥**: 닫혀 있던 광장 "우주항구·루비웨이 방면"(셔틀), 제3행성 해산물 요리점·부유식 상점(매대) 열림. 밤에 "저녁에 시간 있어?", 돔시티에서 "돔시티 나갈 때" 같은 어긋난 대사에 시간·장소 조건. 존댓말 캐릭터(류현석·문성호)의 반말 섞임 수정. 중복 대사 정리
- **반복 줄이기**: 혼잣말 풀을 활동마다 3~5개 → 10개 안팎으로 늘리고, 말풍선·혼잣말·인사·직원 대사 모두 최근에 나온 말을 피해서 고름
- **늘어짐 줄이기**: 부대원에게 말 걸 때마다 뜨던 선택지는 아직 안 물어본 질문이 있을 때만(또는 가끔) 뜸
- **대사·행동 추가**
  - 대위: 장소 대화 30여 곳 추가(PX·의무동·작전동·카페·냉삼집·꽃시장·관광지·다른 행성…), 잡담 16개 + 날씨/시간 잡담, 선물마다 다른 반응 15종, 방문 노크·다음 날 아침·숙박 수락·화해 대사, 메시지 8종
  - 부대원·시민: 지나가면 먼저 인사(하루 한 번, 손 흔들기), 친한 사람은 하트, 짝꿍끼리 말을 주고받음(이준혁↔최민재, 한도윤↔서유진 체스, 오지훈↔김하린, 류현석↔조은별 …), 이름 없는 사람들도 같은 일을 하는 사람끼리 대화
